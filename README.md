# SyFuスタリオン 東京競馬場

> **これはSyFuの非公式ファンアプリです。** SyFu公式（運営）が提供・保証するものではありません。このゲームについてSyFu公式へ問い合わせないでください。

SyFu のキャラクターが東京競馬場を2周するブラウザのレースゲームです。PC とスマホで遊べます。

**▶ 遊ぶ: https://antigrabitybot.github.io/syfu-stallion/**

- ひとりで走る（CPU 9台）、ルームコードでオンライン対戦、観戦モード（予想して払戻）
- 最速タイムのランキング（自己ベストは公開の Nostr リレーに保存されます。タイトル画面のランキングから送信をオフにできます）

このリポジトリには公開用の完成品（ビルド済みファイル）だけが入っています。クレジットは [CREDITS.md](CREDITS.md) を見てください。
